# SpotUs Legal & Policy Documents

This directory contains all legal, policy, and compliance documents for SpotUs, a hyper-local social networking application ("Where locals connect.").

These documents have been generated to ensure compliance with Apple App Store Guidelines, Google Play Policies, GDPR, and CCPA, while addressing the unique location-based and temporary nature of SpotUs interactions.

## Customization Required

Before publishing these documents to production, please search for and replace the placeholder fields (e.g., `[Company Name]`, `[Support Email]`, `[Website URL]`, `[Effective Date]`) in each document. 

## Formats Provided
Each document file includes:
1. **Title** & **Purpose**
2. **Full Legal Document**
3. **Website Version** (for your `/privacy`, `/terms`, etc. routes)
4. **In-App Summary** (shortened bullet points for mobile settings)
5. **Customization Checklist**
